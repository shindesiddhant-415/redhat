## **Fil management


| `head -5 file` | Display first five lines |

| `tail -3 file` | Display last three lines |

| `cp source destination` | Copy a file |

| `yy` | Copy a line in Vim |

| `p` | Paste a copied line |

| `dd` | Delete a line |

| `ln source link` | Create a hard link |

| `ln -s source link` | Create a symbolic link |

| `ls -l` | Display long listing |



## **Users and groups**



| Command | Purpose |

| --- | --- |

| `groupadd -g 50000 database` | Create a group with a specified GID |

| `useradd -G database dbadmin1` | Create user with supplementary group |

| `passwd dbadmin1` | Set user password |

| `chage -d 0 dbadmin1` | Force password change |

| `chage -m 10 dbadmin1` | Set minimum password age |

| `chage -M 30 dbadmin1` | Set maximum password age |

| `su - dbadmin1` | Switch to user |

| `sudo -i` | Open root login shell |

| `chown :database review2` | Change group ownership |

| `chmod g=rwx review2` | Give group full access |

| `chmod o+t review2` | Set sticky bit |

| `chmod g+s review2` | Set setgid bit |

| `chmod o+rx review2` | Give others read and execute |

| `umask 007` | Configure default permission mask |



## **Process management**



| Command / key | Purpose |

| --- | --- |

| `top` | Monitor processes |

| `k` inside `top` | Send a signal to a process |

| `15` / `SIGTERM` | Request graceful termination |

| `q` inside `top` | Quit `top` |



## **SSH and packages**



| Command | Purpose |

| --- | --- |

| `ssh student@serverb` | Connect to remote server |

| `ssh-keygen` | Generate SSH key pair |

| `ssh-copy-id -i key.pub user@host` | Install public key remotely |

| `ssh -i key user@host` | Connect using a specific private key |

| `systemctl reload sshd.service` | Reload SSH service |

| `dnf install zsh` | Install zsh package |



## **Networking**



| Command | Purpose |

| --- | --- |

| `nmcli device status` | Show network device status |

| `nmcli connection show` | Show connection profiles |

| `nmcli connection add` | Create a connection |

| `nmcli connection modify` | Modify a connection |

| `nmcli connection up` | Activate a connection |

| `hostnamectl hostname NAME` | Set hostname |

| `hostname` | Display hostname |

| `ping -c2 IP` | Send two connectivity test packets |



## **File systems and searching**



| Command | Purpose |

| --- | --- |

| `lsblk -fs` | Display block devices and file systems |

| `mkdir /mountpoint` | Create mount point |

| `mount DEVICE MOUNTPOINT` | Mount a file system |

| `df -Th` | Display file-system usage and type |

| `find / -iname filename` | Search by name, ignoring case |

| `find / -user USER` | Search by owner |

| `find / -group GROUP` | Search by group |

| `find / -perm 640` | Search by exact permissions |

| `find / -type f` | Search regular files |

| `find / -size 100c` | Search files of exactly 100 bytes |

| `2>/dev/null` | Discard error messages |
